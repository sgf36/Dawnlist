# ShortDescription — en-GB source

Partner Center's ShortDescription is the line under the app name in search
results. Empty, the Store truncates the long description instead, which opens
"BEFORE YOU BUY — WHAT DAWNLIST DEPENDS ON" — so the first thing a browsing
customer reads is a warning.

Limit is 1,000 characters; short is better. Every claim below is one the
product supports and the long description already makes.

---

Dawnlist reads the job feeds every morning, judges each posting against a
brief it builds with you from your own CVs, and hands you a ranked shortlist
with the reasons stated. Rejections stay visible. It drafts your follow-ups
and never sends them. Runs on your own Anthropic API key.

---

## What this deliberately does not say

- **No "AI-powered".** The long description explains what the AI does and what
  it costs the user; a badge here would be the marketing version of that.
- **No price.** Partner Center shows the base price separately, and this app
  is free to install with the subscription bought elsewhere. A price in this
  line would contradict the button next to it.
- **Nothing about speed or numbers of jobs.** Neither is measured.
